# Sound effects

Short clips loaded by id (file name without extension). Replace any file to change a sound;
keep the name. WAV, ogg or mp3 all work. The shipped pack is synthesized placeholder audio.

| id | when |
| --- | --- |
| jump, jump_horse, jump_cart, jump_griffin, jump_boar, jump_shadowcat | the button makes the mount act (falls back to `jump`) |
| land | touching down after being airborne |
| death | struck by a hazard or a wall |
| rune, rune_big, rune_gravity, rune_dash, rune_void | activating a rune (orb) by type |
| pad, pad_gravity | touching a shroom pad / gravity lily |
| portal, portal_mount, portal_gravity, portal_speed, teleport | crossing a gate |
| coin, gem, key, gate | collecting loot; a locked gate opening |
| waystone | raising a checkpoint in squire mode |
| complete, horn | finishing a quest; setting out from the quest scroll |
| click | interface buttons |

Music and effect volume are set on the main menu under Options and persist between sessions.
